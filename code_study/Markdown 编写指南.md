# Markdown 编写指南

Markdown 是一种**纯文本**就能写出带格式文档的语法。后缀是 `.md`。

---

## 标题

```markdown
# 一级标题（最大）
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题（最小）
```

几个 `#` 就是几级标题，后面加一个空格。

效果：
> # 一级标题
> ## 二级标题
> ### 三级标题

---

## 文字样式

```markdown
**加粗**
*斜体*
***加粗加斜体***
~~删除线~~
`行内代码`
```

效果：**加粗**　*斜体*　~~删除线~~　`行内代码`

---

## 列表

### 无序列表

```markdown
- 第一项
- 第二项
  - 子项（缩进两个空格）
  - 又一个子项
- 第三项
```

用 `-` 或 `*` 都可以。

### 有序列表

```markdown
1. 第一项
2. 第二项
3. 第三项
```

### 任务列表（带勾选框）

```markdown
- [ ] 还没做的任务
- [x] 已经完成的任务
```

效果：
- [ ] 还没做的任务
- [x] 已经完成的任务

---

## 链接

```markdown
[显示的文本](https://github.com)
```

效果：[显示的文本](https://github.com)

## 图片

```markdown
![图片描述文字](图片的路径或URL)
```

## 代码块

\`\`\` 三个反引号包围，并注明语言：

````markdown
​```python
def hello():
    print("Hello, world!")
```
````

效果：
​```python
def hello():
    print("Hello, world!")
```

如果是行内的小段代码，用单个反引号：`print("hello")`

## 表格

```markdown
| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 内容 1 | 内容 2   | 内容 3  |
| 内容 A | 内容 B   | 内容 C  |
```

关键就是第二行的冒号位置：

| 写法 | 效果 |
|------|------|
| `:---` | 左对齐 |
| `:---:` | 居中对齐 |
| `---:` | 右对齐 |

效果：

| 左对齐 | 居中对齐 | 右对齐 |
|:-------|:--------:|-------:|
| 内容 1 | 内容 2 | 内容 3 |
| 内容 A | 内容 B | 内容 C |

不需要对齐列宽，只要符号位置正确就行。

## 转义

如果你想显示 `*` `#` 这类特殊符号本身，在前面加反斜杠 `\`：

```markdown
\* 不会被当成斜体
\# 不会被当成标题
```

## 常用速查

| 你想做的事 | 怎么写 |
|-----------|--------|
| 大标题 | `# 标题` |
| 中标题 | `## 标题` |
| 加粗 | `**文字**` |
| 斜体 | `*文字*` |
| 代码 | `` `code` `` |
| 代码块 | ` ```语言 代码 ``` ` |
| 无序列表 | `- 项目` |
| 有序列表 | `1. 项目` |
| 勾选框 | `- [ ]` 或 `- [x]` |
| 链接 | `[文字](URL)` |
| 表格 | `\| a \| b \|` + 第二行对齐 |
| 分割线 | `---` |
| 引用 | `> 内容` |

## 两个小技巧

### 1. 在 VS Code 里边写边预览

打开 `.md` 文件，按 `Ctrl + Shift + V` 打开预览窗口。左边写右边看，不用猜格式对不对。

### 2. 命名的习惯

- 文件名用英文，因为 GitHub 上中文路径有时出问题
- 可以用 `learning-notes.md` 而不是 `学习笔记.md`

如果必须用中文，也没问题，GitHub 基本支持。
