## *C++*

### Chapter 2 变量和基本类型

#### 2.1 算术类型

分为两类：**整型**（包括字符和布尔型）和**浮点型**。

| 类型 | 含义 | 最小尺寸 |
|------|------|----------|
| `bool` | 布尔 | — |
| `char` | 字符 | 8位 |
| `short` | 短整型 | 16位 |
| `int` | 整型 | 16位（通常32位） |
| `long` | 长整型 | 32位 |
| `long long` | 长长整型 | 64位 |
| `float` | 单精度浮点 | 6位有效数字 |
| `double` | 双精度浮点 | 10位有效数字 |
| `long double` | 扩展精度浮点 | 10位有效数字 |

> 实际大小因编译器和平台而异。**C++ 只保证 `short ≤ int ≤ long ≤ long long`。**

**带符号和无符号**：
- 默认带符号（`signed`），如 `int` = `signed int`
- 无符号加 `unsigned`：`unsigned int`，范围 0 ~ 2^n-1
- 混用有/无符号会有意料之外的类型转换，**建议统一用有符号**（除了位运算场景）

**类型选择经验**：
- 整数就 `int`，不够大换 `long long`
- 浮点就 `double`，精度和性能比较均衡
- 别用 `float` 除非内存特别紧
- 字符就 `char`，别用 `bool` 存字符

**Unicode 字符**：

`char` 只有 1 字节，最多表示 256 种字符，对于英文够用，但碰上中文、日文、emoji 就完全不够了。Unicode 就是用来解决"全世界文字统一编码"的。

**两个概念辨析**：

- **Unicode** — 字符集，给每个字符分配一个唯一编号（"码点"），如 `U+4E2D` = "中"
- **UTF-8 / UTF-16 / UTF-32** — 编码方式，决定"码点怎么存成字节"

C++ 为 Unicode 提供了几种扩展字符类型：

| 类型 | 大小 | 用途 |
|------|------|------|
| `wchar_t` | 2 或 4 字节（平台相关） | 宽字符，老方案 |
| `char16_t` | 2 字节 | UTF-16 |
| `char32_t` | 4 字节 | UTF-32，直接存码点 |

```cpp
char16_t c = u'中';       // u'' 前缀 = UTF-16 字面量
char32_t c2 = U'中';      // U'' 前缀 = UTF-32 字面量
```

> **实际开发中**：UTF-8 最通用（英文字符 1 字节，中文 3 字节），在 C++ 里直接存在 `std::string`（本质是 `char` 序列）里就行，日常用不到 `char16_t` 除非做跨平台文本处理。

#### 2.2 字面值常量

```cpp
20          // 十进制 int
024         // 八进制 → 20
0x14        // 十六进制 → 20
3.14        // double
'a'         // char
"hello"     // 字符串（末尾自动加 '\0'）
true        // bool
```

**转义序列**：`\n`（换行）`\t`（制表）`\\`（反斜杠）`\"`（双引号）`\'`（单引号）
