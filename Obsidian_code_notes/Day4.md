# python

## 第二章：变量和简单数据类型

### 1. 变量

```python
message = "Hello"
print(message)
```

- 变量名只能包含**字母、数字、下划线**，不能以数字开头
- 直接赋值即创建，无需声明类型
- Python 是**动态类型**语言——变量可以重新赋值为不同类型(详见[[编程语言类型]])

### 2. 字符串

字符串既可以由双引号又可以由单引号包裹，这种灵活性可以让我们在字符串中包含引号和撇号

>字符串的合并用加号实现

```python
name = "ada lovelace"
print(name.title())   # Ada Lovelace
print(name.upper())   # ADA LOVELACE
print(name.lower())   # ada lovelace
```

**f-string(Python 3.6+)——字符串里嵌变量**

```python
name = "Alice"
print(f"Hello, {name}!")  # Hello, Alice!
```

**常用方法**：`rstrip()` / `lstrip()` / `strip()` 去空白，`removeprefix()` / `removesuffix()` 去前缀/后缀（3.9+）

> **注意**：只能暂时去除，二次访问还是会有空格，除非二次赋值

**制表与换行**：`\t` 制表符，`\n` 换行符

>使用str( )可以将非字符串值表示为字符串
### 3. 数字

```python
2 + 3    # 5
3 ** 2   # 9（乘方）
3 / 2    # 1.5（总是浮点）
3 // 2   # 1（整除）
```

- 浮点数运算可能产生不精确的小数（`0.1 + 0.2 == 0.30000000000000004`），这不是 bug，是 IEEE 754 浮点(详见[[IEEE754浮点数]])表示固有的
- 大数字用 `_` 分隔：`14_000_000_000`（等价于 14000000000）
- **常量**：全大写命名 `MAX_SIZE = 1000`（约定，Python 无真正的常量）

### 4. 注释

```python
# 这是单行注释
```

Python **没有**多行注释语法。实际中用三引号做多行说明：

```python
"""
这是多行说明，
三引号本来是个字符串，不赋值给任何变量时
运行时会创建后立刻丢弃，效果等同于注释。
"""
```

- 用自然语言解释**为什么**这么做，而非代码本身干了什么
- 三引号也能用 `'''`（单引号版），效果相同
- 写多了自然会判断什么该注释什么不该

### 5. Python 之禅

在终端执行 `import this`，几句核心原则：

> - 简单优于复杂
> - 可读性很重要
> - 面对歧义，拒绝猜测
> - 做一件事最好只有一种明显的方式
