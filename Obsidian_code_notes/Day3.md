# 2.2变量

**定义 vs 声明**：
- **定义** = 类型 + 由变量名组成的列表（变量名用逗号分隔），以分号结束
- **声明** = 告诉编译器"这名字在别处定义了"，用 `extern`

```cpp
extern int i;       // 声明
int j;              // 定义
extern int k = 1;   // 定义（有初始化就抵消了 extern）
```

## 2.2.1 初始化的常见形式
```cpp
int a = 0;   // 拷贝初始化
int b(0);     // 直接初始化
int c{0};     // 列表初始化（C++11）—— 丢数据就报错
int d = {0};  // 同上
```

> **列表初始化的好处**：`int x{3.14}` 会报错（窄化转换），`int x(3.14)` 静默截断成 3。

## 2.2.2 默认初始化
- 函数外定义的变量 → 0
- 函数内定义的内置类型 → **未定义**（什么垃圾值都有）
- 类对象 → 由构造函数决定

> 函数内定义的 `int sum = 0;` 不要偷懒写成 `int sum;`。

简单来说，对象就是具有某种数据类型的内存空间

## 2.2.6 名字的作用域

作用域(scope)

C++中大多数作用域以花括号分隔

### **全局作用域(global scope)**
整个程序范围内有用

### **块作用域(block scope)**
只在所在块内起作用

### **嵌套作用域**

作用域可以彼此包含

被包含的作用域叫**内层作用域(inner scope)**

相应的，包含着其他作用域的称为**外层作用域(outer scope)**  

### **名字隐藏（Name Hiding）**

内层可以重新定义外层的同名变量，外层的那个就被**隐藏**了：

```cpp
int x = 42;
{
    int x = 10;   // 隐藏外层 x
    cout << x;     // 10
}
cout << x;         // 42
```

### **作用域解析运算符 `::`**

被隐藏的**全局**变量可用 `::` 访问（只能跳全局，不能跳"上一级"块）：

```cpp
int x = 42;
{ int x = 10; cout << ::x; }  // 42
```

### **作用域 ≠ 生命周期**

- **作用域**：名字**可见**的范围（编译期概念）
- **生命周期**：对象**存在**的时间（运行期概念）

```cpp
void f() {
    static int count = 0;  // 作用域 = 函数内；生命周期 = 整个程序
}
```

### **其他作用域类型**（后续章节会讲）

| 类型 | 说明 |
|------|------|
| 函数作用域 | 标签（`goto` 目标），C++ 仅此一种 |
| 类作用域 | 成员属于 `类名::` |
| 命名空间作用域 | `namespace Foo { }` → `Foo::xxx` |

> 花括号 `{}` 本质就是创建块作用域——随手写一对裸 `{}` 也是合法的，里面的变量出 `}` 即销毁（RAII、锁管理常用）。
